## Local preview

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8080
# → http://localhost:8080
```

## Deploy

Push to `main` on [tannu371/Portfolio](https://github.com/tannu371/Portfolio) — GitHub Pages serves from the default branch.
